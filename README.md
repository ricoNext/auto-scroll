# Auto Scroll 🔄

一个 Chrome 浏览器扩展，自动滚动当前页面，支持自定义滚动距离和时间间隔。

## 功能

- **自定义滚动距离**：设置每次滚动的像素范围（如 100～200px）
- **自定义滚动间隔**：设置每次滚动的时间间隔范围（如 10～15秒）
- **随机滚动**：每次在设定范围内随机选择滚动距离和间隔，模拟自然阅读行为
- **自动停止**：到达页面底部时自动停止滚动
- **懒加载兼容**：对无限滚动/懒加载页面有 1.5 秒宽限期检测，避免误停
- **配置持久化**：自动记住上次的滚动参数，无需重复配置
- **悬浮按钮**：页面右侧中间提供快捷操作入口，可快速开始/暂停滚动

## 安装

1. 打开 Chrome，访问 `chrome://extensions/`
2. 开启右上角「开发者模式」
3. 点击「加载已解压的扩展程序」
4. 选择本项目目录（`auto-scroll/`）

## 使用

### Popup 配置

1. 点击浏览器工具栏的插件图标，打开配置面板
2. 设置滚动距离范围（px）和滚动间隔范围（秒）
3. 点击「开始滚动」启动，点击「停止滚动」暂停
4. 配置会自动保存，下次打开时自动回填

### 悬浮按钮

启动滚动后，页面右侧中间会出现一个悬浮按钮：

| 状态 | 外观 | 操作 |
|------|------|------|
| 已停止 | 灰色 ▶ | 点击开始滚动 |
| 滚动中 | 蓝色 ⏸ | 点击暂停滚动 |
| 到达底部 | 橙色 ▶ | 点击重新滚动 |

鼠标悬停时按钮展开，显示对应文字提示。

## 权限说明

| 权限 | 用途 |
|------|------|
| `activeTab` | 获取当前标签页的临时访问权限 |
| `scripting` | 按需注入 content script（仅在用户点击开始时） |
| `storage` | 保存滚动配置参数 |

## 设计细节

- **按需注入**：content script 仅在用户点击「开始滚动」时注入，不会在所有页面自动加载
- **Shadow DOM**：悬浮按钮使用 Shadow DOM 隔离样式，不与页面 CSS 冲突
- **状态同步**：popup 和悬浮按钮双向同步滚动状态，任一侧操作都会更新另一侧
- **底部检测**：`scrollTop + clientHeight >= scrollHeight - 2`，2px 容差处理子像素问题
